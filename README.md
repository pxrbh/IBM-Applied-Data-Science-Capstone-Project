# IBM Applied Data Science Capstone Project
This capstone serves as the final project for the Applied Data Science Course offered in the [IBM Data Science Professional Certificate](https://www.coursera.org/professional-certificates/ibm-data-science)

## Project Background 
This capstone aims to make Space Y a competitive company by determining the price of each launch. In order to achieve this,information from Space X rocket launches will be gathered to train a machine learning model that will predict whether the first stage of the rocket launch will be successful or not.

## Project Contents
To achieve that goal, this project underwent the following stages:

1. Data Collection using API
2. Data Collection using Web Scraping
3. Data Wrangling
4. EDA with SQL
5. EDA with Visualization Lab
6. Interactive Visual Analytics with Folium
7. Interactive Dashboard with Plotly
8. Predictive Analysis using Machine Learning
